# PatchPilot documentation

PatchPilot investigates API adapter migrations and produces a patch with source evidence and a tested scope. Start with the [installation guide](../README.md#get-started), then run the bundled key-free replay before configuring live providers.

- [Security](../SECURITY.md): execution boundaries, data handling and responsible reporting.
